## 3. 모니터링할 만한 기술 / 프레임워크

1. **Loop Transformer (룹 트랜스포머)** — GLM-5.4는 GLM-5의 28개 레이어를 2회 반복해 750B로 2~3T급 성능을 주장. 단, Z.ai 스스로 "처음부터 루프로 학습한 모델은 동일 연산 예산에서 아직 일반 모델보다 뒤처진다"고 인정 → *기존 모델을 이어 학습(continued training)하는 방식*이 핵심 포인트.
2. **AI 승인 정책 파일 (Policy-as-code for approvals, 폴리시 애즈 코드)** — Claude Approvals는 저장소 내 정책 파일을 읽고 자동 승인. CI/CD·코드 오너십 관행에 직접 영향.
3. **멀티 벤더 AI 칩 최적화 스택** — Amazon이 Decart Optimization Stack을 Trainium 판매 전 확보. Nvidia CUDA 종속 탈피 시도의 신호.
4. **Agent Skills 표준** — Google까지 공식 참여하면서 스킬이 "에이전트 생태계의 패키지 매니저" 계층으로 자리잡는 중.
5. **Rust GPU UI (Rune)** — 아직 프리릴리스지만 Tauri/egui 이후 Rust 데스크톱 UI의 새 후보.
